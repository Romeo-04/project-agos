## Critical path, and the one thing that can sink the day

```
        ┌─ P1 DATA BUILD (no SAC needed) ──────────┐
START ──┤                                          ├── P3 CHARTS ── P4 ASSEMBLE ── P5 EXPORT
        └─ P2 SAC ACCESS ⚠ RISK ──────────────────┘
```

**SAC access is the only hard blocker.** Everything in Phase 1 runs without it. So Phase 1 and Phase 2 run **concurrently** — SAC login is attempted first thing, and if it stalls, data work continues while it is resolved rather than the day stalling with it.

**Failure modes worth naming up front:**
- SAP SSO/MFA cannot be driven by Playwright → mitigation: user completes authentication manually, automation takes over the live session
- Session timeout mid-build → mitigation: build and save each chart atomically; never hold unsaved work across phases
- SAC model import rejects a CSV → mitigation: all CSVs are pre-validated to SAC's import rules in Phase 1 (flat, headers, no merged cells, ISO dates, no thousands separators)

### Decision required: where the storyboard is assembled

ADSE requires that *charts be generated by SAC* — not that the entire PDF be exported from SAC.

- **Route A — hybrid (recommended).** Build every chart in SAC; export charts; assemble the 15 pages in a layout tool; export landscape PDF. Pros: exact control over page count, 20 MB budget, image compression, and photo/mockup layout. Cons: one extra hop.
- **Route B — SAC-native.** Build the entire storyboard as a SAC Story and export to PDF. Pros: unambiguous SAC provenance; fewer tools. Cons: SAC page layout is far less flexible for full-bleed photography and mockups, and PDF pagination is harder to pin to exactly 15 landscape pages.

Recommendation: **Route A**, with all charts genuinely built in SAC so the provenance requirement is met on the merits.

**Per-chart checklist** (from `AGOS_Storyboard_Plan_v2.md` §4):

## Phase 5 — Export and compliance gate · ~1 hr

Every item is pass/fail against a published rule. Any fail returns to Phase 4.

- [ ] **Exactly ≤15 pages**, excluding references
- [ ] **Landscape** orientation
- [ ] **≤20 MB** total
- [ ] Each embedded image **≤2 MB**
- [ ] Filename `PHILIPPINES_<TEAM NAME>.pdf`
- [ ] Cover carries all six required elements
- [ ] Every chart legible at 100% zoom **and** when printed
- [ ] All charts visibly SAC-generated
- [ ] References page present and complete
- [ ] All copy in English
- [ ] Read end-to-end once, aloud, for narrative flow
